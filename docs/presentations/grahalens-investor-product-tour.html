Chapter 4

How the observatory thinks

Simple words. This is the logic Maya never sees — but trusts when the language stays honest.

Compute first. Speak second.

1 · Birth chart math (on the phone)

From date, time, and place, the app places nine grahas and Lagna using Lahiri whole-sign houses. Numbers are tested against fixtures (within half a degree). The AI is not allowed to invent planets.

2 · Timing & weather

Dasha = which life chapter you’re in (maha / antar).

Sky Weather = four scores for today from transits to your chart: clarity, pressure, friction, opening.

Muhurta = suggested windows inside the civil day.

3 · Lens + grounding

Your question goes out with chart facts and memories. If the model claims “Mars in Leo” and your Mars isn’t there, that line is rejected. Quieter mode still cites real dasha.

4 · Bonds

Two charts → five domains (Talk, Care, Spark, Friction, Growth) with reasons. Visual constellation. Free: one relationship. Private: many.

5 · Journal → memory → patterns

Write offline. Check-ins feed memory. Weekly Pattern Thread (Private) braids moods with sky weather. Soul Cartography builds signatures from the chart.

6 · Private unlock

One entitlement: grahalens_private. Mock store for demos. Real store via RevenueCat when keys exist. Cancel lives in Apple/Google — disclosed on the paywall.

Chapter 5

What’s built vs what’s cloud

Investors ask: “Is the backend done?” Honest answer — in the story’s language.

The brain is on the phone — done

For guest, demo, and daily use, the product logic is implemented:

  • Chart, dasha, weather, muhurta
  • Lens, memory, grounding
  • Bonds, journal, soul, patterns
  • Quotas, paywalls, mock purchase
  • Every screen on the map

Cloud is optional scaffolding — partial

Supabase schema + auth exist. Multi-device sync of journal/bonds is not end-to-end yet. Empty keys = guest mode. That’s a feature for privacy-first seekers like Maya.

  • No separate “API server” for astrology math
  • Store IAP needs RevenueCat keys for TestFlight store mode
  • Push tokens / full sync = next ops layer
Translation: the product works as an observatory today. Cloud sync is the sequel — not the missing plot.
