1. Executive Design Read

Grahalens is not a horoscope mill and not a spiritual chatbot with a chart bolted on. Brand Book ideology wins: dark ink, champagne accents under 5%, sacred computation, adult voice, hairlines over card soup.

Mobbin teaches jobs and IA. Nummi teaches gaps. Neither teaches the Observatory visual world — that stays Brand Book only.

What Mobbin proved

  • Calm / Headspace — one job per screen; monetize after a taste of value or a visible habit loop.
  • Claude — quiet serif empty state, floating composer, privacy moments: closest peer for Lens craft.
  • Moonly / Tinder Cosmic / Nummi — neon, early hard paywalls, vibes without ephemeris “why”: steal jobs, refuse the look.
  • Headspace / Blinkist / Finimize — restore, legal, delete, subscription status in predictable lists (Jakob’s Law).

3. Patterns Top Apps Converge On

  • Onboarding — one question per screen; skip only where Postel allows (birth time); proof before long quizzes.
  • Daily habit — one hero instrument; secondary time-boxed actions; no second companion FAB.
  • Chat — brand empty + 2–4 starters; bottom composer; searchable history; say what memory does.
  • Subscription — free artifact first; two plans; yearly default + trial; restore + soft skip.
  • Trust — Restore / Privacy / Terms / Delete / Export; destructive confirm with sub warning.
  • Settings — grouped hairline lists; birth editable; appearance near top.

  • Habit hero → Sky Weather field (not streak circus)
  • Dual plan + restore → A11 / P1 / X8
  • Domain chips → Bonds without neon
  • Incomplete-data honesty → unknown-time banners

  • Nummi terracotta card soup + dual FAB + early laundry paywall

Strongest 10 UX Decisions

  1. Proof before pay. Soft A11 after free Big Three + houses — never Nummi-style early laundry.
  2. Free chart literacy. Never lock core identity meanings; gate Private depth (Lens/Bonds/Soul/export).
  3. One Sky composition. Wordmark + weather + Lens note + Muhurta — no card soup or lucky widgets.
  4. Claude-quiet Lens. Serif empty, Orb states, 3 chart starters, honest quota — single entry, no dual FAB.
  5. Honest unknown time. Equal-weight “I don’t know”; degrade houses; banner forever until resolved.
  6. Staged computing. A10 milestones (resolve→natal→dasha→weather) — computation trust, not mystical fluff.
  7. Bonds as domains. Constellation + Talk/Care/Spark/Friction/Growth — no neon % soulmate theater.
  8. Habit without streak circus. Daily return via Sky Weather change; Atelier as calm check-in list.
  9. Jakob’s settings. Birth editable, Restore, legal, Finimize-grade delete+sub warning, Ink/Dawn.
  10. Observatory visual lock. Ink/champagne/hairlines/custom tab bar — Mobbin for UX only; Brand Book for look.
