# ABY Journal → Grahalens interface map

Sourced from Mobbin ABY Journal iOS (welcome, onboarding, timeline, insights).
**Style only** — Grahalens content, routes, and computation unchanged.

| Role | ABY (observed) | Grahalens token |
|---|---|---|
| Soft void | `#F5F5F3` / `#FAFAFA` | `dawn.void` |
| Cards | `#FFFFFF` | `dawn.surface` |
| CTA | Black pill | `cta` `#0A0A0A` |
| Accent | Soft lavender / pastels | `accent` `#9B8CDB` |
| Type | Geometric sans (SF/Inter-like) | **Inter** 400–700 |
| Onboarding wash | Lavender→blue / sunrise mesh | `GradientWash` calm/sunrise/journey |
| Progress | Thin segmented bar | OnboardingChrome |
| Press | Soft scale | `SoftPress` |

## Structural translation

| ABY pattern | Grahalens use |
|---|---|
| Full-screen blurred color field | Auth, onboarding, paywall, and top-level tab atmosphere |
| One large prompt per step | Birth date, time, place, confirmation |
| Thin top progress | First-run state without a bulky navigation bar |
| Translucent single-choice rows | Onboarding choices and compact filters |
| Bottom-pinned black pill | The single primary action in the thumb zone |
| Timeline with offset cards | Sky weather, Lens note, muhurta, and archive |
| Stacked daily insight cards | Sky/Atelier summaries and placeholder previews |
| Floating white input/action surface | Lens composer and focused actions |
| Large white content sheet | Chart details, paywall choices, and modal tasks |

The adaptation deliberately excludes ABY's cloud mascot, emojis, journal
language, and proprietary illustration assets. Grahalens supplies all content,
astronomy marks, computations, and navigation.
