# Headspace → Grahalens palette map

Sourced from Mobbin Headspace iOS (home, paywall, settings, onboarding flows).
**Colors only** — we do not clone Headspace mascot, illustration zoo, or IA.

| Role | Headspace (observed) | Grahalens token |
|---|---|---|
| App cream | `#FBF8F3` / `#FFF9F2` | `dawn.void` |
| White panels | `#FFFFFF` | `dawn.surface` |
| Soft peach secondary | `#FFF5F1` | `dawn.raised` |
| Charcoal text | `#2D2D2D` | `dawn.text1` |
| Brand orange | `#F47D31` | `accent` |
| Action blue (CTAs) | `#006AFF` | `cta` / `onCta` |
| Yellow caution | `#E5A100` | `caution` |

## Typography

| Headspace (Mobbin) | Grahalens |
|---|---|
| Custom rounded geometric sans (Apercu / Headspace Sans) | **Nunito** 400–700 |
| One family; hierarchy by weight/size | Same |
| Bold large headlines, open body leading | `displayL` / `title` / `body` |
| Soft labels, not shouty all-caps | `meta` sentence case |
| — | IBM Plex Mono for chart degrees only |

## Motion & interaction

| Pattern | Implementation |
|---|---|
| Soft press | `SoftPress` — scale 0.97 |
| Screen enter | `ScreenEnter` — fade + rise + stagger |
| Tab active | spring bubble behind icon |
| Carousel | elongating orange dots |
| Sheets | large radius + soft rise |
| Surfaces | `Surface` elevation card/float |
